Problem4 Java starter project

IntelliJ에서 여는 방법:
1. ZIP 파일을 압축 해제합니다.
2. IntelliJ에서 압축 해제한 Problem4 폴더를 엽니다.
3. Gradle 프로젝트로 불러오고 Gradle 동기화가 끝날 때까지 기다립니다.
4. src/main/java/project/App.java의 main 메서드로 실행합니다.

주의:
- 이 프로젝트는 Java + Spring Boot 연습용 기본 틀입니다.
- API 경로와 요청/응답 형식은 과제 안내문을 확인한 뒤 구현하세요.
- TODO 부분은 의도적으로 비워 두었습니다.
- 과제 환경이 Java 17이 아니라면 build.gradle의 Java 버전을 과제 환경에 맞추세요.
