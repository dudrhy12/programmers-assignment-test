Problem5 Java + Spring Boot practice project

IMPORTANT:
- This is a separate Java/Spring Boot practice project for IntelliJ.
- It is NOT the original Problem5 project.
- It does NOT run or satisfy the original JavaScript tests at tests/problem.spec.js.
- The sample endpoints and sample data are for learning Java controller/filter logic only.
- Update endpoint paths and response shapes if you want to practice against the full problem statement.

Open in IntelliJ:
1. Extract this ZIP.
2. Open the Problem5_Java_Practice folder in IntelliJ.
3. Import/sync as a Gradle project.
4. Wait for Gradle sync.
5. Run src/main/java/project/App.java.

Practice tasks:
1. Implement filtering by authorId in GET /api/posts.
2. Implement/adjust the author list for GET /api/posts/authors.
3. Test the endpoints and compare results against your expected behavior.
